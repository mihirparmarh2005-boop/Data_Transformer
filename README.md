# Data Transformer – MySQL SQL Project

## 📌 Project Overview

This project is a MySQL-based data transformation and analysis project.

It contains customer, order, and employee data and demonstrates different SQL concepts such as:

- SELECT queries
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL OUTER JOIN simulation
- Subqueries
- Aggregate functions
- Date functions
- String functions
- Window functions
- RANK()
- CASE statements
